# SwiftBill

Simple invoicing for freelancers worldwide. Static site (`index.html` + policy pages), no server; data stays in the browser.

Owner settings are at the top of the script in `index.html`:
`CHECKOUT_URL`, `GUMROAD_PRODUCT_ID`, `CUSTOMER_CODES`, `CONTACT_EMAIL`, `GOATCOUNTER_CODE`, `MAX_DEVICES`, `FREE_PER_MONTH`.
The contact email also appears in `privacy.html`, `terms.html`, `refund.html`.

Branches: work on `dev`, merge to `main` after checking (GitHub Pages serves `main`).
